# Viva Service24 · site web

Static site (HTML, CSS, vanilla JS, no framework, no build needed to run it) for Viva Service24, cleaning company in Crissier. Built for Google Ads traffic: every page leads to a call, a WhatsApp message or the 2-step quote form.

## Change the phone, e-mail or form address
Edit `js/config.js`. `VIVA_EMAIL` at the top is the address that receives the quote requests. The phone number also appears in the HTML: change `PHONE` and `TEL` in `tools/build.py`, then run `python3 tools/build.py`.

## FormSubmit activation (do this once)
The form posts to `https://formsubmit.co/ajax/info@vivaservice24.ch`. The very first request sends an activation e-mail to that address: open it and click "Activate Form". Until then requests are not delivered and visitors see the "appelez-nous" fallback message. Test once yourself after publishing.

## Add a review
Edit `js/reviews.js`: copy a block, paste it at the top, change name, date (YYYY-MM-DD), service and text (verbatim). If the total changes, update "16 avis" in `tools/build.py` and rebuild.

## Google Ads
In `js/config.js` set `googleAdsId` (e.g. `AW-123456789`) and the conversion labels:
- `lead`: fired once per session on `merci/` (use this as the main form conversion),
- `call`: any click on a phone link,
- `whatsapp`: any click on a WhatsApp link.

When the ID is empty nothing is loaded from Google. Events are always pushed to `window.dataLayer` (`call_click`, `whatsapp_click`, `form_step2`, `generate_lead`, `lead_thank_you_view`, `estimator_cta`), so Google Tag Manager can be used instead. `gclid`, `gbraid`, `wbraid` and the UTM parameters are kept in sessionStorage and sent with each request. When an Ads ID is set, a small notice lets visitors refuse (stored in localStorage).

## Editing pages
Pages are generated by `tools/build.py` (shared header, form, reviews, footer). Edit texts there and run `python3 tools/build.py`. CSS: `css/critical.css` (inlined in every page by the build: header, hero, form) and `css/site.css`. Images: `python3 tools/build_images.py` (needs Pillow; sources in `_src/`, not committed).
